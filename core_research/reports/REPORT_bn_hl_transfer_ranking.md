# Binance→Hyperliquid Best price 전이·cross-market FV 순위와 두 전략 갈래

2026-11-08. 2026-10-15~11-01 KST의 네 퍼프를 사용했다. 처음 하루는 학습, 이후17일은 매일 이전 날짜만으로 확장 학습했다. 기존 연구에 사용한 기간이므로 새로운 미사용 holdout이 아니다.

## 핵심 판단

동일 기초자산에서 BN mid·잔량가중 micro의 변화와 HL best bid/ask의 반응은 뚜렷하다. 수신시각 기준 반응 정점은 대체로500ms, native-clock 기준은200~300ms다. 반응 정점과 주문 도달 뒤 남는 예측 신호의 수명은 다른 숫자다.

주 비교(h=1/5/30초, age=1초, 고정 계수, 동일기초 쌍)의 36개 신호 프로필 중 native 양쪽 라벨·bid/ask 연속 지연구간 스크린 통과는 30개, 최소500ms까지 통과는 0개다. 이는 통계적 탐색 스크린이며 운용 승인이 아니다.

원래 의사결정의 BN·HL 정보를 모두 고정하고500ms 이후만 본 강화 검사에서는 양쪽 가격·두 sampling phase의 동시 하한이 양수인 family/window 조합이 0/48개다. 신호를 일부러 오래된 것으로 바꾸면서 현재 HL 정보를 계속 갱신하는 실험과, 주문을 보낸 뒤 정보를 갱신하지 못한 채 기다리는 실험을 합치지 않았다.

따라서 이번 강화 기준으로 긴 주문 지연을 견디는 실행 후보를 확인했다고 말할 수 없다. 아래 순번은 다음 검증의 우선순위이며, 유효한 전략이 있다는 뜻이 아니다.

## 신호·모형·라벨

`mid=(bid+ask)/2`, `OBI=(Qbid-Qask)/(Qbid+Qask)`, `micro=(ask*Qbid+bid*Qask)/(Qbid+Qask)`다. 여기서 micro는 L1 잔량가중 proxy다. Stoikov의 상태전이로 적합한 micro-price를 구현한 것으로 부르지 않는다.

`micro-mid=(spread/2)*OBI`이므로 특히 1틱 스프레드가 많은 BN에서 micro와 OBI가 독립된 새 정보라고 해석하면 안 된다. OFI는 정적 잔량차가 아니라 최우선 가격·잔량 변화 이벤트의 순유입이며100/500/1000ms 창으로 정규화했다.

| 모형군 | BN 추가 정보 |
| --- | --- |
| Mid | 100/500/1000/5000ms 수익률 + 과거 basis로 옮긴 가격차 |
| Micro proxy | 같은 창의 잔량가중 가격 수익률 + 옮긴 가격차 |
| OBI | 잔량 불균형 수준과100/500/1000ms 변화 |
| OFI | 100/500/1000ms 정규화 order-flow imbalance |
| Joint | 위 신호 결합; 중복·공선성은 수치 rank 처리 |
| Mid+OFI | mid가 이미 있는 상태에서 OFI의 조건부 추가가치 |

기준선은 HL 자체 스프레드·OBI·weighted offset·100/500/1000ms 수익률·OFI다. 모든 추가가치는 같은 표본의 이 기준선 대비 MAE 감소로 계산했다. 현재 bid/ask 유지 예측도 보조 기준선이다. 서로 다른 마스크에서 얻은 절대 MAE를 그냥 비교하지 않는다.

가격 수준은 과거300초 반감기 log basis로 보정했다. 지연 d를 넣을 때 basis도 t-d에 알 수 있었던 값만 썼으며, 현재 BN 정보를 오래된 신호에 몰래 넣지 않았다. 보통주형↔ADR형 교차쌍의 변환은 통계적 가격 보정이며 경제적 헤지 교환비율의 확정이 아니다.

| 라벨 | 예측 대상 | 용도 |
| --- | --- | --- |
| receive | 앞으로 수신될 HL quote 변화 | 서버가 보게 되는 가격의 예측·피드 catch-up 포함 |
| native innovation | 미래 native quote − 현재 native quote | 남은 시장 이동 진단; 현재 native 기준값은 offline 정보 |
| native endpoint | 미래 native quote − 현재 수신 quote | 절대 FV 후보; feed catch-up과 미래 이동을 함께 포함 |

100ms 입력·가격 해상도에서 주 의사결정은1초 phase0이다. h는100/500ms와1/5/30초, 추가 BN 나이는0~1초의 세밀한 격자 및1.5/2/3/5/10/30/60초다. source freshness는 원래 관측 시점에서1초/5초를 적용하고 의도적인 d를 별도로 기록한다. 따라서 d를 와이어 지연의 실측값으로 해석하지 않는다.

고정 계수(frozen)는 d=0에서 전일까지 학습한 모형에 오래된 BN과 현재 HL을 넣는다. 지연별 재학습(refit)은 각 d에서 과거로 다시 설계한 잠재 성능이다. 후자가 살아 있어도 같은 신호를 늦게 실행해 살아남았다는 증거는 아니다.

## 두 전략 갈래와 다음 실행 순서

| 구분 | 양방향 maker MM | FV 기반 일방향 Alpha |
| --- | --- | --- |
| 목표 | 양쪽 유동성 공급의 체결조건부 기대가치와 재고 위험 관리 | 남은 방향성 가격 이동을 포지션 이익으로 전환 |
| 필요한 FV | 양쪽 미래 bid/ask와 체결조건부 가치·취소 위험 | 롱 청산 bid / 숏 청산 ask와 도달시 실행가격 |
| 신호 승인 | 활성·취소 지연을 감싼 양쪽 가치와 quote 불확실성 | 실제 기다린 뒤 남는 한 방향 EV가 비용 하한을 초과 |
| 주문 | FV 중심 양면 + inventory/toxicity + 미제출 후보 | 방향 선택 후 IOC/taker 또는 별도 검증한 maker |
| 재고 | 목표 재고와 미체결 주문을 포함한 위험 한도 | 포지션 크기·기간·FV 소멸/반전·청산 규칙 |
| 다음 증거 | 실제 주문 활성/취소·자기 queue·cancel/fill race | 실제 도달 bid/ask·거부·부분체결·보유 구간 비용 |

같은 FV라도 목적함수와 체결 조건이 다르다. Maker 주문으로 들어가는 Alpha도 있으므로 maker/taker 주문유형으로 두 전략을 구분하지 않는다. 양쪽 EV가 음수인 MM은 미제출을 허용해야 하며 이전 강제 호가384설정의 결과를 최적 MM이나 새 전략의 수익으로 재사용하지 않는다.

실행 우선순위는 (1) 상위 진단 FV의 양쪽·native·전체 의사결정 고정 검사 확인, (2) 활성·취소·데이터의 정확한 구간과 p90/p99 측정, (3) 새 날짜의 고정 모델 shadow, (4) 실행 EV가 남는 갈래만 수량·체결 실험으로 진행하는 순서다. MM은 양쪽 및 취소 위험이 남을 때, Alpha는 한 방향의 실제 청산 호가 EV가 비용을 넘을 때만 다음 단계로 보낸다.

상세 수식·진입/청산·재고·미제출·검증 및 기각 기준: [두 전략 연구계획](/Users/Kang/projects/Perp_research/PLAN_cross_market_MM_alpha.md). HL taker/taker 왕복 수수료만0.576bp이고 spread/slippage는 추가다. HL maker −0.03bp는 자격 가정이다. 예측 MAE 감소를 그대로 거래당 bp 수익으로 변환하지 않는다.

## 검증 근거와 범위

- 72개 입력 파일, 62,208,000개100ms 격자. 반복 스냅샷 수를 독립 표본 수로 세지 않았다. 원본asof/OFI272값 대조와 기존1초canonical parity를 통과했다.
- 주 평가 582,624개 일별 프로필, 34,272개 요약. 모든 프로필17개 순차검증 날짜이며 첫날과 당일 미래 라벨을 학습에 사용하지 않았다.
- 응답곡선472,680개 모멘트 행의18일×26,260행, clock/source/target/feature/lag/side/phase 키 유일성·각101개lag 완전성을 확인했다. 반응 peak는 전체18일 기술통계다.
- 모멘트 scalar/batch의 실제2,424행 대조 정규화 오차2.21e−11, source feature72market-day 전수에서 valid source51,089,995행의 비유한 feature0개를 확인했다. Synthetic +300/−300ms, partial 식별성, 충분통계 대조 등을 검증했다.
- 주 예측 신뢰구간은 날짜 단위2,000회 bootstrap이며 선택한 고정 예측의 변동을 평가한다. 매 bootstrap에서 재학습한 전체 모델 선택 불확실성이 아니다. family×lag×양쪽의 동시 band를 추가했지만 모든 clock/horizon/거래 아이디어 탐색을 망라한 실거래 승인 검정은 아니다.
- NTP/PTP 로그, 실제 개인 주문 체결·대기열, p90/p99 활성·취소 지연, 시장충격과 과거 계약 명세의 완전한 보존은 확인되지 않았다. 이 보고서는 예측·전이·연구 우선순위이며 새로운 PnL 백테스트가 아니다.
